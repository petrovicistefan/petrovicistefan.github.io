mcp-dealfinder

Product search for AI assistants, with honest affiliate links.

mcp-dealfinder is a small server that lets an AI assistant look up products from merchants' official feeds, compare them, and hand back a buy link. If a link earns a commission, it says so.

Status: early preview. The server runs locally on the user's own computer. A public release is planned and this page will be updated when it happens.

How it works

  1. The user connects mcp-dealfinder to an AI assistant that supports the Model Context Protocol.
  2. The user asks something like “find noise-cancelling headphones under 150 EUR and compare the top two”.
  3. The assistant searches product data loaded from merchants' own affiliate feeds and shows prices, merchants and links.
  4. Every link that can earn a commission carries a visible disclosure.

Principles

  • Official data only. Product data comes from feeds and APIs that merchants and affiliate networks provide for this purpose. No scraping.
  • Disclosure on every affiliate link. The server returns the disclosure text together with the link and instructs the assistant to show it.
  • Ranking ignores commission. Results are ordered by how well they match the search, or by price when the user asks. Commission rates are not part of the ranking.
  • No invented facts. The assistant is told to state only what is in the product data: price, brand, category, description.
  • Prices can be out of date. They are as of the last feed refresh and are not converted between currencies. The merchant's page is always the source of truth.
